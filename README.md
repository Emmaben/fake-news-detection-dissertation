# Fake News Detection Dissertation

## Overview

This project presents a comparative study of classical machine learning models and transformer-based models for fake news detection under cross-domain conditions.

## Models Used

* Logistic Regression
* Support Vector Machine (SVM)
* BERT (bert-base-uncased)
* RoBERTa (roberta-base)

## Datasets

* LIAR Dataset
* ISOT Fake News Dataset

## Methodology

* TF-IDF for classical models
* Hugging Face Transformers for deep learning
* Cross-domain evaluation (LIAR ↔ ISOT)

## Results

Significant performance degradation observed under domain shift, highlighting limitations in model generalisation.

## Tech Stack

* Python
* Scikit-learn
* Hugging Face Transformers
* Pandas, NumPy
